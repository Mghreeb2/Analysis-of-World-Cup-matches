# FIFA Men's World Cup match Analysis
## Overview
This project analyzes FIFA Men's World Cup match data using Python. It includes data cleaning, exploratory data analysis (EDA), and visualizations to discover interesting insights from the dataset.

## Tools
- Python
- Pandas
- Matplotlib

## Project Highlights
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Total Goals Scored
- Average Goals per Tournament
- Top 10 Teams by Goals Scored
- Top 10 Teams with the Most Draws
- Top 10 Teams by Penalty Shootout Wins
- Most Successful Teams in World Cup History
